⏰ Relógio Digital

Projeto desenvolvido para praticar JavaScript, trabalhando com manipulação do DOM, eventos e atualização de conteúdo em tempo real.

O relógio exibe a hora atual do sistema e é atualizado automaticamente a cada segundo.

💻 Sobre o projeto

A proposta foi criar um relógio simples e funcional, utilizando JavaScript para obter a hora atual e atualizar o conteúdo exibido na página automaticamente.

Projeto desenvolvido para praticar e consolidar fundamentos de JavaScript.
